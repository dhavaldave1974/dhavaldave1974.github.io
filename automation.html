AI automation with n8n

A sample workflow that turns a new customer inquiry in Gmail into a calendar event, an Excel record, a quotation and an invoice. I built it hands-on in n8n as part of my work on workflow automation and Forward Deployed Engineering.

n8nGmailGoogle CalendarExcel / SheetsAI extractionPDF quotationInvoice

Workflow overview

Sample n8n workflow, from a new email to an invoice.

Jump to a step

1. Read the Gmail account

2. Collect data from the new inquiry

3. Create a calendar event

4. Generate an Excel sheet of new inquiries

5. Create the quotation

6. Send the quotation and raise the invoice

1. Read the Gmail account

A Gmail Trigger node watches the inbox (or one label) and starts the workflow for each new email. An IF node separates real inquiries from other mail, using keywords or an AI check.

  • n8n nodes: Gmail Trigger, IF, AI node
  • Output: sender, subject, body, attachments

2. Collect data from the new inquiry

An AI information-extraction step reads the email text and returns clean fields, so nobody has to retype them.

  • Name, company, phone, email
  • Service or product requested, quantity or scope
  • Budget and preferred date or deadline
  • Missing details are flagged for a follow-up question

3. Create a calendar event

A Google Calendar node creates a meeting or follow-up slot from the preferred date in the inquiry, with the client’s email as guest and the inquiry summary in the description.

  • n8n node: Google Calendar (create event)
  • If no date is given, the event is set for the next free working day

4. Generate an Excel sheet of new inquiries

Each inquiry becomes a new row with a unique inquiry number, date, extracted fields and a status column. A Google Sheets or Microsoft Excel 365 node adds the row, or a Spreadsheet File node writes an .xlsx file.

  • Columns: inquiry no., date, client, need, budget, status
  • Status moves from New to Quoted, Approved, Invoiced

5. Create the quotation

A template (Google Docs, or HTML turned into PDF) is filled with the client’s details, line items, price, tax and validity date. The PDF is saved to Drive and its link is written back to the Excel row.

  • Quotation number generated automatically
  • Prices come from a rate list in a sheet
  • I add a human approval step, so nothing goes to a client unchecked

6. Send the quotation and raise the invoice

After approval, a Gmail node emails the quotation. When the client accepts, the workflow creates an invoice from the approved quotation (invoice number, items, tax, due date), sends it as PDF and marks the row Invoiced.

  • Accounting tools can be connected through an HTTP Request node
  • Reminders can be added for unpaid invoices

Safeguards

  • Human approval before any quotation or invoice reaches a client
  • Credentials stored in n8n’s credential manager, never in the workflow
  • Error branch that notifies me and logs the failed email
  • Tested with sample emails before going live
